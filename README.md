# Bank Management System

## Project Description

This is a Java Swing Bank Management System developed using Object-Oriented Programming concepts.

## Features

- Create Account
- Login
- Check Balance
- Deposit Money
- Withdraw Money
- Transfer Money
- Transaction History
- Save Data to File
- Load Data from File
- Logout

## Technologies Used

- Java
- Java Swing
- File Handling
- OOP
- VS Code
